# Original synthesized samples

`bd.wav`, `sd.wav`, and `hh.wav` were procedurally generated for this project on 2026-11-06 with Python's standard library; they contain no third-party recordings. They are dedicated to the public domain under CC0-1.0 (https://creativecommons.org/publicdomain/zero/1.0/). They are deliberately small starter sounds, not a comprehensive drum library.
