# Architecture and trust boundaries

`shared/contracts.ts` describes JSON tracks, revisions, transport and envelopes. `shared/tool-schema.json` is a single generic proposed tool schema, 588 UTF-8 bytes including newline; it is **not registered in Hermes**. The service validates operation fields. `server/store.js` owns tracks, sections and snapshots, serializes operations within one process, uses expected revisions and writes a sibling temporary file then atomically renames. The browser owns ephemeral playback. One service process per data file: no cross-process locking, durability fsync, or access control for other local processes.

Host (`src/Host.tsx`) calls the loopback service and embeds the editor in an opaque `sandbox="allow-scripts"` iframe. The editor exchanges version-1 `{version,id,type,payload,capability}` envelopes with the host, validating the window source and random per-frame capability; the editor also checks host origin. Reload creates a new capability. The host handles `ready`, `init`, `tool.request`, `tool.result`, `refresh`, `display`, and `transport`. The capability is held by the editor and authorizes its host-mediated tool calls: it is not a user identity or a backend authorization token. Host displays request traffic. Payload validation is minimal and does not yet cover all typed variants; production use needs stricter schemas and limits. `postMessage('*')` to the opaque frame is delivery only, not authorization.

**Code execution boundary:** The editor never evaluates patterns itself. Its nested, separately opaque `sandbox="allow-scripts"` audio iframe (`src/Audio.tsx`) receives only code and tempo; controls inside that frame require a click. The engine (`src/engine/`) runs Strudel JavaScript in that nested realm, which never receives the editor/host capability. The parent accepts no privileged calls from the audio frame. The backend rejects Origin `null` and non-configured browser origins, and Vite's development middleware limits opaque-frame requests to player source, generated dependencies and samples. These measures are not an OS sandbox: arbitrary JavaScript may hang its renderer, consume resources, make outbound requests, and exploit browser or dev-server vulnerabilities. The loopback API has no token for local non-browser processes and the middleware is not a hardened asset server. Do not treat this as safe for hostile content or deploy publicly. A production Hermes bridge needs authenticated transport, scoped permissions, reviewed source/asset isolation, CSP/egress policy, and user authorization.

Audio starts only from its own frame's controls; mock host transport validates a request but cannot actuate the isolated child. Editing changes the child buffer and clicking Play/apply performs evaluation; invalid evaluation leaves the previous pattern running in the tested case. Evaluation side effects cannot be rolled back. Pattern updates use Strudel's scheduler, not guaranteed bar-quantized changes. Muting uses destination gain, limited to 0–1. Reloading or unmounting destroys the audio realm and stops playback. Sections are individual patterns, not a timeline sequencer. There is no recording, offline export, audio metrics UI, or perceptual analysis.
