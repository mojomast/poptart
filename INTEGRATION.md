# Hermes integration (scaffold, not yet connected)

Verified against Hermes source commit `486f4a6a9918a4054373e33a200260ffd501645e`; installation and runtime are untested. The adapter in `integration/hermes/` deliberately registers no tools and its Desktop pane shows setup instructions, because a secure authenticated service bridge has not yet been established. Do not mistake discovery or pane rendering for end-to-end integration.

Hermes native plugin discovery expects `plugin.yaml` and `__init__.py` with `register(ctx)`; register tools using `ctx.register_tool(name=..., toolset=..., schema=..., handler=...)`. A handler accepts `(args: dict, **kwargs)` and returns a JSON string. Only after designing authenticated local IPC, create a lean schema exposing supported operations and translate responses from the service; do not pass credentials to the iframe or make the listener public. Enforce user approval for edits and playback at the trusted boundary.

Desktop uses a separate entry `desktop/plugin.js` exporting `{id,name,register(ctx)}`; pane contributions use `area:'panes'` and `render`. Its SDK exports `SandboxedFrame`, which enforces opaque-origin `allow-scripts`. The provided entry is only a setup stub. Build an authenticated host mediator and use SDK frame, not a raw webview. Do not automatically evaluate remote code. A pane unmount kills playback; use a persistent separately isolated player if uninterrupted pane navigation is necessary, and revalidate security and audio.

Web dashboard UI uses a distinct `dashboard/manifest.json`, SDK and bundle. Its backend module `dashboard/plugin_api.py` exports a FastAPI `APIRouter` mounted at `/api/plugins/<name>/`; Desktop can use the same backend namespace. Dashboard and Desktop enablement are separate, as is enabling the Python backend. Refer to upstream docs for the currently installed version. No dashboard manifest or backend router is claimed as implemented here.

Synchronization: fetch authoritative revisions on reconnect and after a frame reload; if live updates are added, authenticate the Hermes WebSocket using its documented gateway mechanism and fall back to bounded revision polling if unavailable. Neither a WebSocket nor polling bridge is implemented in this scaffold. Remote gateways require explicit placement, authentication and secure transport; never assume `localhost` means the Desktop machine. Test `hermes plugins install` and `hermes plugins doctor` on an actual installation before packaging for the catalog.
