# Research — 2026-11-06

## Inspected versions and sources
- [Toaster](https://github.com/vanities/toaster-strudel) `1b53c590b1d84e9eff2904cdd29dae1e719c7014`: inspected `web/src/engine/{strudel,prelude,tracks,recorder,render}.ts`, `web/src/App.tsx`, track polling, composition tools and skills. Repository LICENSE is GPL-3.0; root package.json's ISC value conflicts with that file. The player imports `@strudel/web@1.3.0` and soundfonts from unpkg, and expects an asset mirror not present in the checkout. Its custom prelude, analysis, recording and banks are not automatically transferable as standalone dependencies. Importing its whole server would also introduce its Claude integration. Adapt selectively.
- [Strudel](https://codeberg.org/uzu/strudel) is the canonical npm repository; [REPL internals](https://strudel.cc/technical-manual/repl/) describe transpilation and dynamic JavaScript evaluation, 50ms scheduler tick, 100ms minimum latency and continuous pattern replacement. `@strudel/webaudio` npm declares AGPL-3.0-or-later. Strudel is not a security sandbox.
- [Hermes](https://github.com/NousResearch/hermes-agent) `486f4a6a9918a4054373e33a200260ffd501645e`: `website/docs/developer-guide/plugins/index.md`, `plugins/google_meet`, `website/docs/developer-guide/desktop-plugin-sdk.md`, `apps/desktop/src/components/ui/sandboxed-frame.tsx`, dashboard extension documentation, `plugins/kanban/dashboard` and fixture `tests/fixtures/plugins/example-dashboard`. Native plugin `register(ctx)` calls `ctx.register_tool(name,toolset,schema,handler)`; handlers return JSON strings and accept `(args, **kwargs)`. Desktop plugin is separate ESM `desktop/plugin.js`, pane via `ctx.register({area:'panes',...})`. Web dashboard has `dashboard/manifest.json` and its own JS SDK; `dashboard/plugin_api.py` exports FastAPI `router`, mounted at `/api/plugins/<name>/`. Desktop docs warn renderer enablement does not enable Python backend. Do not infer remote gateway deployment from local paths.
- Desktop SDK `SandboxedFrame`: scripts allowed, opaque origin, no referrer, lazy, disallows same-origin; caller cannot set iframe `allow`. Other Hermes preview frames vary; this is the verified closest target, not a universal Hermes policy. Frame unmount tears down its realm.
- [MDN iframe](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe), [postMessage](https://developer.mozilla.org/en-US/docs/Web/API/Window/postMessage), [secure contexts](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Secure_Contexts): opaque origin messages report `null`, not an identity; check window source and capability, validate payloads, and never expose privileged commands to evaluated guest code. AudioWorklet requires secure context; localhost is potentially trustworthy but embedded ancestors also matter. Browser autoplay generally requires a user gesture. Sandbox does not prevent network exfiltration, resource exhaustion or privilege misuse through a permissive bridge.

## Decisions and unresolved issues
Bundle exact npm versions rather than engine CDN. GPL-3.0 and AGPL-3.0 section 13 permit combination; modified GPL portions remain GPL, new code AGPL-3.0-or-later, retain notices and provide corresponding source, including network users when required. Package license metadata and all actual assets must be audited before distribution; NOTICE is not a substitute for an exhaustive release audit. No unlicensed sample pack should be redistributed. A browser iframe is a containment layer, not a complete hostile-code sandbox: never grant it backend credentials and do not automatically evaluate agent edits. Hard resource isolation and egress restrictions require additional deployment controls.

Playback should retain one context, require gesture, keep the prior working pattern on evaluation failure, and distinguish scheduled/evaluated code from measured output. For synchronization use revision checking, atomically persisted state and reconnect with authoritative refresh; do not equate a transport request with successful playback. Hermes runtime, capability permissions, lifecycle, sandbox audio and remote gateway behavior require empirical validation (see TEST_REPORT.md).
